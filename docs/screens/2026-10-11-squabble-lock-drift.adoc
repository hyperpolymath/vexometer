== Reconciliation method (honest)

The `gh actions-lock` generator (`github/gh-actions-lock`) is a Go gh-extension
whose release binaries are unreachable from the authoring sandbox (egress
allowlist blocks `release-assets.githubusercontent.com`, and no Go toolchain or
module proxy is available to build from source). The lock was therefore
reconciled by hand *to generator format*, with every metadata field
API-verified:

* `dtolnay/rust-toolchain@e2a55d2ffb04f378e9626c28d38b36d230d1e12f` — verified
  commit; lightweight tag `refs/tags/v1` points at it (matches the YAML comment)
* `hyperpolymath/smtp-notify-action@c1c9fa07992a02c1fd3d67a0dc1b08cccb852aef` —
  verified commit; annotated tag `v0.5.0` resolves to it (matches the YAML
  comment)
* superseded pin entries removed; reusable-workflow closure entries (e.g.
  `dtolnay/rust-toolchain@6c977a6…` via `hyperpolymath/standards`) untouched
* local scripted check: every `uses:` pin in `.github/workflows/*.yml` is in
  the lock, and every workflows-section pin has a dependency entry

The gates themselves are the machine proof.

== What the dead CI was hiding

Quality Gates had not run since 2026-10-01 (17 `startup_failure` runs
2026-10-02 → 2026-10-10). PR #109's Ada therefore merged *without ever being
compiled*. To surface the compiler's verdict through the one channel reachable
from the authoring sandbox, `quality-gates.yml` now re-emits `just test-all`
failures as check annotations (chunked tail-first: the annotations API keeps
roughly the first ten created). Four defects were found and fixed:

[cols="1,3,2", options="header"]
|===
| # | Defect | Fix

| 1
| `Float_Array` declared in `vexometer-metrics.ads`'s *private* part, after
  the public functions that use it (`Float_Array is undefined` at the first
  signature)
| Type moved to the visible part before `function Mean`

| 2
| Operator visibility in `test_runner.adb`: `=`/`/=` on
  `Interfaces.Unsigned_64` and `=` on `Answerability_Kind` "not directly
  visible"
| `use type` clauses; same class preempted in `vexometer-metrics.adb`
  (`use Interfaces` for the LCG arithmetic)

| 3
| Ambiguous `Append` call with an unqualified aggregate
  (`a-convec.ads:471` Vector overload vs `:483` Element_Type overload — Ada
  cannot resolve an aggregate when both candidates are visible)
| Qualified `Response_Analysis'(...)` aggregate

| 4
| *Logic bug* in the bootstrap `Draw` of `Compare_Models`:
  `Positive (x mod N) + 1` applied the conversion *before* `+ 1`, so any zero
  draw raised `CONSTRAINT_ERROR : range check failed`. With
  `Bootstrap_Draws = 2000` a crash was immediate.
| `+ 1` moved inside the conversion; comment updated
|===

Defect 4 is exactly the class of bug the dead gate existed to catch: the
scoring-correctness work of #109 shipped a comparison function that crashed on
its first real run.
